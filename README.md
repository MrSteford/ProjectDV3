позывной + пароль · локальный сейф · без облака на основном пути

## Идея
Дневник как **сейф**.  
Записи лежат в зашифрованных `.pdenc`-блобах. Без позывного и пароля архив нечитаем — даже вне приложения. Карточки списка открывают только крошечный sidecar с превью, а не гигабайты видео.
> Without the key the archive stays unreadable — even outside this app.
---
## Возможности
| | |
|:---|:---|
| **Сейф** | AES-256-GCM · PBKDF2 · callsign входит в ключ |
| **Запись** | Камера + HUD-виджеты · 16:9 / 9:16 · пауза · теги · закладки |
| **Голос** | Команды на лету (Vosk / Whisper): закладка, пауза, стоп |
| **Плеер** | Избранное · заметки · транскрипт · конспект · итог сессии |
| **Календарь** | Настроение дня · заметка · стрик · ачивки · статистика недели |
| **Поиск** | По смыслу, проекту, голосу, избранному, названию записи |
| **AI локально** | Whisper · Qwen · эмоции — без обязательного облака |
---
## Как это работает
```
Пароль / позывной
        ↓
   Календарь-архив
        ↓
  ● Записать сейчас  →  виджеты в кадре  →  .pdenc + .meta.pdenc
        ↓
   Плеер · поиск · итог
```
1. Разблокируй сейф  
2. Выбери день в календаре  
3. Запиши лог (план речи, теги, голосовые метки — по желанию)  
4. После стопа запись упаковывается в хранилище  
5. Смотри, ищи, отмечай ★, давай названия видео  
День помечается избранным, если **хотя бы одно** видео этого дня в избранном.

## Требования
- **ОС:** Windows 10 или 11, **x64**
- **Железо:** камера и микрофон  
  NVIDIA / AMD **не обязательны** (хватит обычного ПК; HW-энкодер только ускоряет, иначе `libx264`)
- Установщик подтянет при необходимости: .NET 8 Desktop, WebView2, VC++ x64
---
## Установка
Скачай установщик из **[Releases](../../releases)** (когда релиз опубликован):
1. Запусти `ProjectDiarySetup.exe`  
2. При первом входе задай **позывной** и **пароль** (или открой уже существующий сейф)  
3. Позывной — не просто ник: он участвует в ключе шифрования  
> Не теряй позывной и пароль. Без них архив не восстановить.
